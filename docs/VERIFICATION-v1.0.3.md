## 本次公开构建

- 六组纯 Java 测试通过，包括所有型号默认不选择品牌素材的回归检查。
- Android SDK 编译、D8、zipalign 及 APK v2 / v3 签名验证通过。
- APK 的 assets 只包含素材使用说明，不包含耳机产品图片、视频、录屏或原始资源包。
- 默认展示本项目原创线条耳机图形；保留图片、动图、视频导入，以及独立的型号与外观配置。
- 按发布者要求，本次公开 APK 未重新安装至手机，也未做该 APK 的设备回读验证；手机保留原有本地版本。

## 此前功能实测范围

iQOO 16 / OriginOS + FreeBuds 6i：本地构建已实测桌面后台连接卡片、每次重新连接电量查询、与智慧音频显示一致的左右耳 / 盒子电量、佩戴收起和手动关闭。公开版保留相关蓝牙与状态处理路径，移除的是内置品牌素材及其加载路径。

未验证所有 Android 版本、手机系统、长期熄屏和重启恢复，也未认证 FreeBuds Pro 5。盒盖收起依赖实际连接断开，不代表接入独立盒盖状态传感器。

设备标识、个人设备名称、原始日志及录屏原件均不公开。
