# 耳机弹窗 v1.0.3

首次公开发布。公开源码与安装包不包含华为或 vivo 产品素材，默认使用本项目原创线条耳机示意，产品图片和动画由用户自行导入。

## 连接提示与后台运行

- 基于已配对蓝牙设备、音频连接事件和系统伴生设备关联，在桌面及其它应用上方直接显示原生卡片。
- 监听启用 / 关闭与手动预览分离，保留独立的设备与型号配置。
- 优化连接去重与断开清理；明确 vivo / iQOO 的“允许后台耗电”设置要求。

## 外观与动画

- 新的线条耳机图标、居中文字按钮和无黑色描边的圆角按键。
- 可调位置、偏移、宽度、素材高度、圆角、底色、透明度、裁切方式和视频播放速度。
- 支持导入图片、GIF / WebP、MP4，素材复制到应用私有目录，移动源文件后仍可使用。
- 自定义素材内叠放标题、关闭按钮和电量组件。
- 导入视频与动图按文件帧顺序持续循环；可使用自己准备的同向、首尾衔接素材。

## 电量与收起行为

- FreeBuds 6i 每次有效连接后自动读取真实电量，缺失字段显示未知。
- 左耳、右耳、充电盒动态电池图标；弹窗移除手动电量刷新按钮和旧数据提示。
- 自动卡片保持显示，直到检测到佩戴、连接断开或用户关闭。
- 支持已验证的 2B25 佩戴状态与兼容的 2B03 状态帧；状态通道仅在自动弹窗可见时保持。
- 保留智慧音频，可继续调整耳机预设。

## 安装与适配边界

最低 Android 8.0 / API 26。需要蓝牙连接、悬浮窗、通知及系统设备关联。OriginOS 用户请允许后台耗电。

已实测 iQOO 16 / OriginOS + FreeBuds 6i。FreeBuds Pro 5 仅预留型号配置，其素材、电量、佩戴尚未实测。盒盖未接入独立传感器，目前通过合盖后发生的连接断开联动收起。长期熄屏、重启恢复和其它 OEM / 固件组合尚未认证。

公开版本不包含品牌产品图片、动画、录屏、第三方应用 APK 或私有资源包。
