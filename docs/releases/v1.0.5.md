# 耳机弹窗 v1.0.5

本次正式发布累计包含 v1.0.4 和 v1.0.5 的改动，相比 v1.0.3 主要改善自定义素材弹窗的显示和耳机本体叠加。

## 弹窗显示修复

- 修正卡片底部圆角外的投影暗边，背景、视频和遮罩使用一致的圆角轮廓。
- 去掉关闭按钮下方的黑色底块，保留白色叉号、点击区域和按下时的涟漪反馈。

## 自定义素材与耳机本体

- 新增“显示耳机本体”开关，按型号独立保存，默认关闭。
- 耳机本体与自定义背景分别管理，可独立更换或清除。
- 支持导入已抠图的透明 PNG 或静态 WebP；不透明图片、动画及无效文件会被拒绝，导入失败时保留原配置。

## 配套旋转素材的支持范围

- FreeBuds 6i 在包含本地配套素材的构建中，恢复原视频的三维旋转和原生循环；Android 13 / API 33 及以上可实时去除白色背景，更早系统使用配套静态透明图。
- 公开 APK 不附带品牌产品图片或旋转视频。公开版使用本体叠加时，请先导入自己的透明 PNG / 静态 WebP；导入的本体图片保持静态。

## 安装与验证

- 版本号 `1.0.5`，版本代码 `9`；最低 Android 8.0 / API 26，目标 SDK 35。
- 延续 v1.0.3 的签名，可直接覆盖升级并保留原有设置和导入素材。
- 已通过全部六组纯 Java 测试、Android SDK 编译、D8、zipalign，以及 APK v2 / v3 签名验证。
- 本地配套素材构建已在 iQOO 16 上验证原视频循环、透明背景及关闭按钮。公开 APK 从不含私有素材的 Git 源码快照单独构建，尚未单独安装到手机验证。
